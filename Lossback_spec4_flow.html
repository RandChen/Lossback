Changelog

  1. Lossback 範圍與排他規則：by Match（單一賽事）或是 by Period（跨賽事）
    • by Match：Match 狀態是 Operations 在 Admin site 有開盤，單場賽事官方結算完成時觸發計算與派發
    • by Period：活動週期結束且該週期內所有賽事均已結算完成後，才執行全期總淨虧損計算並派發一次
    • 系統會自動過濾掉已被該家 Licensee 選定、排定、正在進行中的賽事，避免重複建立同一場賽事
  2. 淨虧損計算公式細化與盈利排除機制：
    • by Match：指定賽事之總有效投注額 - 總派彩金額（計算結果為負值）
    • by Period：活動週期內指定賽事之累計總有效投注額 - 累計總派彩金額（計算結果為負值）
    • 回饋百分比
      • 前置判定：若總派彩金額 ≥ 總有效投注額（全期結算為盈利或平手），淨虧損計為 0，不符合門檻亦不派發回饋
      • 回饋公式：回饋 Free bet = min(淨虧損絕對值 × 回饋百分比, 回饋Free bet上限)
      • 回饋Free bet計算後若有小數點，則無條件捨去
    • 回饋絕對金額
      • 輸入淨虧低消、回饋絕對金額
  3. Free bet setup 正式整合至 Campaign setup：
    • 無需跨系統操作，直接於 Promotion Suite 設定派發之 Free Bet 規則：
      • 適用範圍：All or by League, Sport, Bet type
      • 適用賠率：最低賠率, 最高賠率
      • 適用時間：Start time to End time
  4. 內部 Free bet API 和外部 Bonus API 規格：
    • 新增派發 Free bet API：系統調用 Free bet API 派發 Free Bet
    • 新增 recall free bet API：當賽事 reSettle 時，系統調用 recall Freebet API 回收 Free bet，依照現有 Free bet 系統邏輯
    • 外部 Bonus API 規格：制定外部 Bonus API 規格文件，以利通知 Licensee 的 3rd party 獎勵 / Bonus 系統派發 Free bet
  5. 活動建立流程模組化重構（Basic setup 與 Campaign setup）：
    • Basic setup（共用層）：涵蓋多 Licensee 建立權限（主站可幫自己與 Subsidiary 建立、Saba 內部人員可跨建）、站點 ID 顯示、多語系名稱/Banner/T&C、排序權重（1 至 99）與曝光起訖時間
    • Campaign setup（專屬層）：涵蓋 User group（手動/CSV/BI 標籤）、範圍選取、淨虧低消與回饋比例設定、Free bet setup
  6. Campaign Preview 預覽畫面呈現完整性：
    • 預覽畫面完整呈現 Basic setup 與 Campaign setup 設定內容
    • 若為 by Period 活動，可預覽 Lossback 活動進度條：
      • 顯示「玩家當前累計有效淨虧損 vs 最低門檻（淨虧低消）」
      • 達成門檻後顯示預計可得之 Free Bet 累積額度
  7. 已審核 Campaign 變更權限鎖定：
    • 審核通過（Approved）之 Campaign 僅允許修改 External name、排序權重與曝光時間；其餘核心欄位（Licensee、User group、範圍、淨虧低消、回饋百分比、回饋 Free bet 上限、Free bet setup）全數鎖定不可變動
  8. Report 報表分權設計：
    • Saba 權限：可查看跨全平台、跨多間 Licensee 的整體彙整數據
    • 主站權限：可查看主站及其 Subsidiary 的數據
    • Subsidiary：可查看本身 Subsidiary 的數據
    • 指標明訂包含觸發場次（by Match）或期數（by Period）及發放金額
  9. 可上傳Banner，有分Desktop和Mobile
  10. 可設置Promotion的排序和曝光時間
  11. 前端平台支援：
    • 支援 Mars（Desktop / Mobile）、Galaxy（Desktop / Mobile）、2.0（Desktop）、Standard（Mobile）

Promotion Suite phase 2 - Lossback

1. LAP｜Promotion Suite ( Create Campaign )

1.1 Basic setup - 共用

  • Licensee and User group
    • Saba內部人員 - 可幫一家或多家Main site和Subsidiary創建Campaign
    • Main site - 可幫自己和Subsidiary創建Campaign
    • Subsidiary - 可幫自己創建Campaign
    • 要顯示Licensee site ID
    • 每一間Main site和Subsidiary可以各自設定User group
      • Manually enter
      • CSV upload
      • Saba BI tag and import
  • Campaign internal name
  • Select Languages
    • Campaign External name
    • Banner
      • Desktop
      • Mobile
    • T&C
  • Promotion page
    • Campaign排序權重 - 1 至 99，1排在最前面
    • Campaign曝光時間 - Start time to End time

1.2 Campaign setup - only for Lossback

  • 選取範圍: by Match(單一賽事)或是by period(跨賽事)
    • by Match：Match狀態是Operations在Admin site有開盤, 單場賽事官方結算完成時觸發計算與派發。
    • by Period：活動週期結束且該週期內所有賽事均已結算完成後，才執行全期總淨虧損計算並派發一次。
    • 系統會過濾掉已被該家Licensee選定、排定、正在進行的賽事，避免被選取同一場賽事
  • Free bet計算方式: 回饋百分比或回饋絕對金額
    • 回饋百分比
      • 輸入淨虧低消、回饋百分比、回饋Free bet上限
      • 淨虧損計算：
        • by Match：指定賽事之總有效投注額 - 總派彩金額（計算結果為負值）
        • by Period：活動週期內指定賽事之累計總有效投注額 - 累計總派彩金額（計算結果為負值）
        • 若總派彩金額 ≥ 總有效投注額（全期結算為盈利或平手），淨虧損計為 0，不符合門檻亦不派發回饋
      • 門檻判定：淨虧損絕對值 ≥ 淨虧低消
      • 回饋 Free bet = min(淨虧損絕對值 × 回饋百分比, 回饋Free bet上限)
      • 回饋Free bet計算後若有小數點，則無條件捨去
      • 需要考量因不同幣別的匯率，如何設定和呈現
    • 回饋絕對金額
      • 輸入淨虧低消、回饋絕對金額
      • 需要考量因不同幣別的匯率，如何設定和呈現
  • Free bet setup
    • 適用範圍 - All or by League, Sport, Bet type
    • 適用賠率 - 最低賠率, 最高賠率
    • 適用時間 - Start time to End time

1.3 以下注單不適用(待確認)

  • Bet Type
  • bet type id 9 - Mix Parlay
  • bet type id 10 - Outright
  • bet type id 29 - System Parlay
  • BB+
  • 468 Score Box Handicap (比分让球盘)
  • 469 Score Box Over/Under (比分大小盘)
  • Bet slip status
  • Multiple single bet
  • Parlay Bet / single bet of Via Lucky
  • SMP / Cash Out / Saba Coins Betting
  • Quick Bet

1.4 Preview Campaign and submit for approval - 共用

  • 可以preview Campaign，包含Basic setup和Campaign setup的內容
  • 若是 by Period，可以 preview Lossback活動進度條
    • 顯示「玩家當前累計有效淨虧損 vs 最低門檻（淨虧低消）」
    • 達成門檻後顯示預計可得之 Free Bet 累積額度
  • 若Preview Campaign後沒有問題，則可以送出給Manager審核，狀態變為In-Review
  • 若Manager審核Campaign不通過，需填寫理由，狀態變為Rejected
  • 若Campaign rejected後，申請人可以按edit，進行重新編輯，狀態變為draft
  • 若Campaign審核通過，即會依其條件進行，狀態變為Approved
  • Campaign可以被暫停或刪除
  • 審核過後的Campaign僅External name、排序權重、曝光時間可以修改，其他內容例如Licensee、User group、範圍、淨虧低消、回饋百分比、回饋Free bet上限、Free bet setup都不可變動

1.5 Review Campaign report(待確認) only for Lossback

報表的資料可見範圍須依 Saba、主站、Subsidiary權限區隔

  • 活動名稱、活動期間及活動狀態。
  • Licensee、站點、運動、聯賽、賽事及盤口。
  • 適用會員數及參與會員數。
  • Lossback 觸發場次（by Match）或期數（by Period）及金額。
  • 觸發Free bet API的張數及金額
  • 觸發Bonus API的張數及金額
  • Turnover、GGR 及Margin
  • 報表篩選及 CSV 匯出。

2. Lossback calculator

於現有系統上新增 Lossback 條件判斷及結算流程

  • 判斷注單、賽事、盤口、會員及活動是否符合資格。
  • 當達到結算時機（by Match: 賽事結算；by Period: 週期結束且全數賽事結算）並符合 Lossback 條件時，系統調用 Free bet API 派發 Free Bet。
  • 防止重複觸發。
  • 記錄觸發條件、觸發時間、比分、結算結果及失敗原因。
  • 支援失敗重試、異常監控及人工查詢。

3. 內部Free bet API和外部Bonus API規格

  • 新增派發Free bet API - 系統調用 Free bet API 派發 Free Bet。
  • 新增recall free bet API - 當賽事reSettle時，系統打recall Freebet API回收Free bet，依照現在Free bet系統的邏輯
  • 需要制定外部 Bonus API規格文件，以利通知Licensee的3rd party 獎勵/Bonus系統派發Free bet

4. Member Site

  • 通知User得到Free bet
  • Free bet的使用依照現有的邏輯和流程

  • 需支援Mars（Desktop／Mobile）, Galaxy（Desktop／Mobile）, 2.0（Desktop）, Standard（Mobile）
